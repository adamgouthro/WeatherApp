<h1>Mobile Weather App</h1>
<p>This mobile weather app will display real time weather information, pulled from an API, you will be able to check the weather in a <strong>"Home"</strong> screen for the current weather, and in a <strong>"Week"</strong> screen to see a forecast of the upcoming weather. This application is being created as i attend NSCC's Mobile Development course as a IT Programming Student.</p>

<h2>Tech Stack</h2>
<ul>
  <li>Kotlin</li>
  <li>Android Studio</li>
  <li>Jetpack Compose</li>
</ul>
